SiteCloner package for Laravel ecosystem.

## Requirements

- PHP: ^8.2
- illuminate/support: `^11.0|^12.0|^13.0`

## Installation

Install the package via Composer:

```bash
composer require alex-kassel/site-cloner
```

## Usage

```php
use AlexKassel\SiteCloner\SiteClonerServiceProvider;

// Implementation example
```
